# Hold'em Coach

A browser based Texas Hold'em practice table. You play against five bots and
every decision you make is graded the moment you make it, with an explanation
that talks about your actual cards, your actual seat and the actual price you
were offered. Every piece of poker jargon anywhere in the interface is
tappable and opens a plain definition with an example.

It is a poker game first. The coach never pauses the game, never asks you to
dismiss anything, and never undoes what you did. The hand carries on
underneath while you read.

## What is in here

```
index.html          the whole interface
manifest.json       makes it installable as an app
sw.js               offline cache
css/style.css       dark table, portrait iPhone first
js/cards.js         deck, shuffling, seven card hand evaluator
js/engine.js        betting state machine, side pots, showdown
js/bots.js          five opponents with distinct personalities
js/coach.js         the rule engine that grades your decisions
js/glossary.js      every term, its definition and an example
js/ui.js            rendering
js/app.js           wiring, storage, screens
icons/              app icons, generated by scripts/make-icons.py
scripts/make-icons.py
test/engine.test.mjs
```

No build step, no bundler, no framework. Plain HTML, CSS and ES modules, so
what is in the repository is exactly what runs.

## Running it

Any static file server works. From the repository root:

```
python3 -m http.server 8000
```

Then open `http://localhost:8000`. Opening `index.html` straight off disk
will not work, because ES modules need a real server.

## Turning on GitHub Pages

1. Push this repository to GitHub with the files at the repository root.
2. On GitHub, open the repository and go to **Settings**.
3. In the left sidebar, choose **Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Set the branch to **main** and the folder to **/ (root)**, then press
   **Save**.
6. Wait a minute or two. The page will show the address, which looks like
   `https://<your-username>.github.io/<repository-name>/`.

Every path in the app is relative, so it works from a repository subpath
without any configuration.

## Adding it to an iPhone Home Screen

1. Open the GitHub Pages address in **Safari** on the iPhone. This only works
   in Safari, not in Chrome or in an in-app browser.
2. Tap the **Share** button (the square with the arrow pointing up).
3. Scroll down and tap **Add to Home Screen**.
4. Tap **Add**.

Launching it from the Home Screen icon opens it fullscreen with no browser
bar and no address bar. After the first load it works with no network at all,
because the service worker caches every file.

If you update the site later, bump `CACHE_NAME` in `sw.js` so the old cache is
thrown away and the new files are picked up.

## The coach

`js/coach.js` is an explicit rule engine, not a guess. It works out the
recommended action from the game state and then compares yours against it.

Verdicts have three levels, because plenty of poker spots have two acceptable
answers:

- **Good** is the recommended action.
- **Fine** is defensible. A different reasonable player would do it.
- **Mistake** is a clear error, and only these count against you.

Before the flop, when nobody has raised, your hand is checked against a six
handed opening chart for your seat:

| Seat | Opening range |
| --- | --- |
| Under the gun | 66+, A8s+, KTs+, QTs+, J9s+, T9s, 98s, ATo+, KQo |
| Hijack | 55+, A7s+, K9s+, Q9s+, J9s+, T8s+, 98s, 87s, ATo+, KJo+ |
| Cutoff | 22+, A2s+, K8s+, Q8s+, J8s+, T8s+, 97s+, 87s, 76s, 65s, A9o+, KTo+, QJo |
| Button | 22+, A2s+, K2s+, Q5s+, J7s+, T7s+, 96s+, 86s+, 75s+, 64s+, 54s, A2o+, K8o+, Q9o+, J9o+, T9o, 98o |
| Small blind | 22+, A2s+, K5s+, Q7s+, J8s+, T8s+, 97s+, 86s+, 75s+, 65s, A5o+, K9o+, QTo+, JTo |

Facing a raise, it re-raises with QQ+, AK and a few suited aces, calls with
pairs, suited broadway cards and suited connectors, widens in the big blind
because of the discount, and widens again when the raise came from a late
seat.

After the flop it works out your made hand, your draws, your out count and the
pot odds you are being offered, then compares the two. When a draw is
involved the banner always shows the arithmetic, so you can see where the
number came from rather than being told to trust it.

Bet sizing is graded loosely. Only clearly wrong sizes get flagged, such as a
tiny bet with a huge hand on a board full of draws.

Mistakes are counted by category and the Stats screen lists your leaks with
the worst first.

## The bots

Five personalities, and each one plays visibly differently:

| Name | Style |
| --- | --- |
| Ada | Tight, plays very few hands, almost never bluffs |
| Bo | Loose and passive, calls far too much, rarely raises |
| Rey | Aggressive, raises constantly, bluffs often |
| Juno | Calls almost anything and will not fold a pair |
| Kit | Balanced, plays close to correct poker |

Tap any opponent to see a one line read on how they play. Reads unlock after
you have played twenty hands against them.

## Settings

Table size of six, nine or heads up. Coach on or off. Blinds of 1 and 2, 2 and
5, or 5 and 10, with your stack always one hundred big blinds so the game
plays the same at every level. There is also a reset that clears all stats.

Anyone who runs out of chips is topped back up to a full stack at the start of
the next hand, so a practice session never ends because somebody busted.

Progress is kept in `localStorage` on the device, so it survives closing the
app and is never sent anywhere.

## Tests

```
node test/engine.test.mjs
```

No dependencies, it uses the Node test assertions directly. It covers:

- every hand category, in the correct order
- wheel straights (A2345) and steel wheels
- straight flushes beating four of a kind
- kicker comparisons at every position, and ties
- split pots and side pots, including a short stack that cannot win them all
- betting that must not deadlock: all in spots, everyone folding to the big
  blind, the big blind's option, short all in raises that do not reopen the
  betting
- a fuzz run over ten thousand random seven card hands, checking every result
  against an exhaustive search of all twenty one five card combinations
- a fuzz run over thousands of random hands at two, six and nine seats,
  asserting that chips are never created or destroyed and that every hand
  terminates
- the coach itself, including a fuzz run that grades hundreds of decisions and
  checks that every term the coach links to actually exists in the glossary
